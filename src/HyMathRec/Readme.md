# Get recommendations using HyMathRec

HyMathRec consist of two main parts, InitialRanker and ReRanker. Results of InitialRanker are used by ReRanker which produces a final ranked list of recommendations.

## Step 1: HyMathRec-InitialRanker

To get results of HyMathRec InitialRanker please run:

```python ./InitialRanker/init_ranker.py -docID=176625``` 

- Where "docID" is an internal document identifier of a zbMATH Open document (please refer to the folder data/ for more info).
- The above script will generate an initial ranked list produced by HyMathRec stored in a pickle file.
- The generated pickle file will be used by the below reRanker to get final ranked zbMATH Open docIDs as recommendations.

## Step 1: HyMathRec-ReRanker

```python ./Re-ranker/custom_reranker.py``` 

- The above file prints the docIDs of top 10 generated recommendations for docID specified in the HyMathRec-InitialRanker script above.
- Additionally upto 1000 ranked recommendations docIDs are stored in a pickle file generated by the script.
- More info in "data/" on how to access document content associated with each docID.
